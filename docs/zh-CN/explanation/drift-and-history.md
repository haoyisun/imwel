# 漂移与 history 仓

## 「漂移」指什么

漂移是以下三者之间的偏离：

1. 你关心的远程模板提交，
2. imwel 记录的上次安装状态，
3. 消费者目录当前磁盘上的文件。

imwel 用 Git 检测——不另造并行内容哈希。

## 为何要隐藏 history 仓

在 `.imwel/history/` 下，imwel 维护一个**真实的 Git 仓库**记录已安装状态。于是可以：

- 用正常 Git 语义做 diff 与 `imwel rollback`
- 本地手改与上游更新重叠时做三路合并
- 用标准冲突标记交给人处理——**从不**静默自动解决

## 为何检查要节流

普通 CLI 命令上的被动远程提示（默认数小时一次）只报告**远程分支 tip 移动**。不同步文件、不检查本地手改，也从不挂钩 AI 工具的聊天会话。显式的 `imwel status` / `imwel sync` 总会刷新。
